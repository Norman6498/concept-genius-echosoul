# EchoSoul — Acceptance / Regression Checklist

## Conversation
- [ ] Text session starts, streams, persists, and resumes.
- [ ] Just Listen does not force advice.
- [ ] Post-listening choices work.
- [ ] User can end without choosing an experience.
- [ ] English/Hindi/Hinglish behavior is natural.

## Voice
- [ ] Mic permissions handled.
- [ ] STT errors have recovery UI.
- [ ] TTS can pause/stop/replay.
- [ ] User can switch to text.

## Memory
- [ ] Meaningful candidates extracted.
- [ ] Trivial statements rejected.
- [ ] Private sessions never persist memory.
- [ ] User can confirm/edit/delete.
- [ ] Relevant memory surfaces.
- [ ] Irrelevant sensitive memory does not surface.
- [ ] Why-is-this-remembered explanation works.

## Novel
- [ ] Chapters are based only on approved content.
- [ ] Fact/reflection are visibly distinct.
- [ ] Reflection can be corrected.

## Literature
- [ ] Every result has author/title/source/rights metadata.
- [ ] Source text equals stored source text.
- [ ] Original language preserved.
- [ ] Author filter works.
- [ ] Language filter works.
- [ ] Hybrid ranking is measurable.
- [ ] Feedback works.
- [ ] Unauthorized modern copyrighted text is not indexed.

## Animated Words
- [ ] No text mutation by renderer.
- [ ] Devanagari/Urdu/Latin shaping works.
- [ ] Handwriting reveal looks natural.
- [ ] Line breaks preserved.
- [ ] Replay/pause/speed works.
- [ ] Attribution is readable.

## Creative
- [ ] Concept is shown before generation.
- [ ] User can edit/cancel.
- [ ] Job status and retries work.
- [ ] Failed jobs do not lose the moment.

## Plans
- [ ] Small action prioritized.
- [ ] Goals require user creation/confirmation.
- [ ] Habits can be completed/edited.

## Safety
- [ ] Ordinary sadness is not over-escalated.
- [ ] High-risk inputs enter safety path.
- [ ] Creative generation is blocked/redirected where needed.
- [ ] Anti-dependency checks pass.
- [ ] Safety is not premium-gated.

## Security/privacy
- [ ] RLS verified.
- [ ] Client contains no secrets.
- [ ] Logs minimize private text.
- [ ] Export/delete works.
- [ ] Private session verified at DB level.
