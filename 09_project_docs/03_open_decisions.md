# EchoSoul — Decision Register

These do not block the product concept but must be resolved during implementation.

1. Frontend framework: Next.js/React, Expo/React Native, Flutter, or staged web-to-mobile.
2. LLM provider/model + failover.
3. STT/TTS providers and cost/latency constraints.
4. Image/animation/video providers.
5. Embedding model dimension. **Do not assume 1536 if the chosen provider differs; migration/schema must match the real embedding size.**
6. Initial public-domain literature corpus and legal review process.
7. Exact UI visual language and handwriting asset strategy.
8. Regional safety resource directory ownership/update schedule.
9. Billing provider.
10. Analytics/event taxonomy with privacy review.
11. Data retention and backup deletion policy.
12. Encryption strategy for particularly sensitive fields.
