# Antigravity Execution Sequence

Use the individual stage prompt files.

For each stage:
1. Read the existing repository and relevant product/UI documentation.
2. Read the stage prompt.
3. Inspect the matching reference image.
4. Implement ONLY that stage.
5. Reuse the existing design system/components.
6. Do not replace unrelated working code.
7. Run typecheck/build/tests.
8. Perform responsive verification.
9. Summarize changes and stop.
10. Wait for explicit approval before starting the next stage.

Stages:
1A Landing
1B Login/Signup
1C Personalization
1D Application Shell
1E Home
1F Talk + Post-Listening
1G Words + Music + Scenes
1H Moments + Journey + Settings
