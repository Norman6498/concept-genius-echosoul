# EchoSoul UI Review Checklist

Before accepting every stage:

- [ ] Does this look like a premium consumer product, not an admin dashboard?
- [ ] Is there clear hierarchy and one dominant primary action?
- [ ] Are public marketing pages separated from the authenticated product?
- [ ] Is the user's actual name/profile used rather than demo names?
- [ ] Does desktop use intentional panels/navigation?
- [ ] Does mobile use an intentional mobile composition rather than a shrunken desktop?
- [ ] Are states included: loading, empty, error, disabled, success?
- [ ] Are keyboard/focus states present?
- [ ] Is contrast readable?
- [ ] Is motion subtle and purposeful?
- [ ] Are mock data and real data clearly separated?
- [ ] Are there no fake claims, fake memories, or fake emotional diagnoses?
- [ ] Are secrets absent from client code?
- [ ] Does the stage build without breaking previous stages?

Acceptance rule:
Do not proceed to the next layer when the current layer still looks like a generic dashboard or template.
