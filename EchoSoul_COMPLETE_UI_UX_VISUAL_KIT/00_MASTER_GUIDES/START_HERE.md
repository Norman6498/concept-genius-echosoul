## Antigravity rule
Do NOT ask Antigravity to “copy the screenshots.”
Tell it to reproduce the locked layout, hierarchy, typography, component behavior, environment layering and motion while using the supplied assets.

## Living environment
Never flatten a living environment into one JPG. Use separate layers and the motion system:
sky → clouds → mountains → foliage → architecture → lamps/glow → weather → particles → UI.

## Locked product behavior
The user speaks/types naturally. EchoSoul listens first, understands the current moment plus relevant history, then surfaces what may help:
Words / Music / Scene / Plan / Perspective / Stay Here.

Search is secondary discovery, not the primary experience.
