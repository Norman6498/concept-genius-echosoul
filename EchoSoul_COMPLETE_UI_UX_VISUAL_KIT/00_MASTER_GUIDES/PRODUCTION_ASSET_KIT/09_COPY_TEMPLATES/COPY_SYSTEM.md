# EchoSoul Copy System

## Principles
Human, concise, emotionally intelligent, never generic.
Listen before advice.
Do not force poetic language into every response.
Use poetry/literature only when relevant.
Never fabricate source text or user history.

## Dynamic templates

Premium: "Start free. Go deeper when you're ready."
