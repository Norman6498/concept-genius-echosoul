# EchoSoul Production Asset Kit — Master Instructions

This package is for implementing the locked EchoSoul UI with real reusable assets and motion.

## Use
- SVGs are production-ready and scalable.
- Backgrounds are layered-ready concept environments.
- CSS motion can be imported directly or translated into Motion/GSAP/Rive.
- JSON presets define timing and behavior.
- Component SVGs are visual state references, not interactive components.
- Use page asset maps to decide which environment layers belong to each page.

## Critical
Do not flatten the environment into one screenshot.
Do not use fake quotes or fake social proof.
Do not hard-code a user's name.
Do not force search-first UX.
Do not paywall essential safety/privacy/support.
