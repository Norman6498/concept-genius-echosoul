# EchoSoul Motion Constitution

Motion must communicate life, not demonstrate animation skill.

## Global rules
- Default motion is slow and organic.
- Avoid infinite identical loops.
- Use multiple offsets and slight randomness for natural elements.
- UI transitions: 180–420ms.
- Environment transitions: 1.5–8s depending on change.
- Primary scene movement can be continuous but low-amplitude.
- Hover responses should be subtle.
- Respect prefers-reduced-motion.

## Signature effects
Leaves: irregular 6–12s cycles, low amplitude.
Clouds: slow continuous drift, independent layers.
Lamp: irregular brightness/glow variation.
Moon/sun: gradual atmospheric movement.
Particles: low-density, varied trajectories.
Path: soft traveling glow on Journey.
Literature: ink/writing reveal; source text must remain exact.
Scene transitions: crossfade + depth/parallax rather than abrupt image replacement.
