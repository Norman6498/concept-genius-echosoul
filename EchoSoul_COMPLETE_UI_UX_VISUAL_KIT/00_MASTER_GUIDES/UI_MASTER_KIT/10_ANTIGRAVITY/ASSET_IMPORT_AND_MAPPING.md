# Asset Import & Mapping

Place production assets under `/public/echosoul/assets/`.

Suggested tree:
public/echosoul/assets/
  brand/
  icons/
  environments/
    dawn/
    morning/
    afternoon/
    evening/
    night/
    late-night/
  pages/
    landing/
    home/
    talk/
    music/
    words/
    scenes/
    moments/
    journey/
    novel/
    settings/
    premium/
    pricing/

Use the manifest files in `06_ENVIRONMENTS`.
Each asset must have a stable semantic filename.
Do not reference generated screenshot filenames in production UI.
