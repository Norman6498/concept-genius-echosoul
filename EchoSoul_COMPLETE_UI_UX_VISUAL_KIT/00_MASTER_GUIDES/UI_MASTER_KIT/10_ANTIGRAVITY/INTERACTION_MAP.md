# EchoSoul Interaction Map

## Global shell
Left toggle:
expanded ↔ compact.
Right panel toggle:
visible ↔ hidden.
Immersive mode:
both panels minimized; environment gains space.

## Home
Talk is primary.
For This Moment is dynamic.
Continue Where You Left Off resumes unfinished experiences.
Search is universal discovery, secondary to personalized recommendations.

## Talk
Voice/text input.
Response appears progressively.
Relevant modules can unfold:
Words / Music / Scene / Plan / Perspective / Stay Here.
User can dismiss or open any module.

## Music
Recommendations first.
Intent chips: calm, sleep, focus, motivation, energy, healing.
Search is secondary.
Hindi and other supported music are first-class.

## Words
Chosen For You first.
Explore second.
Language/script selector.
Listen, save, source/provenance, more like this.

## Scenes
Need-first selection.
Enter / Preview / Customize / Save.
Voice command supported.
Scene controls: ambience, weather, sound, music, intensity, duration.

## Moments
Write/Speak.
Journal / Mood / Gratitude / Dreams / Letters / Milestones.
Save meaningful moment.
Optional memory approval where appropriate.

## Journey
Timeline nodes.
Hover/focus reveals moment.
Path glow follows selected/current position.
Ask questions by voice/text.

## Life Novel
Read.
Chapter navigation.
Story facts/reflections/narrative presentation remain distinguishable internally.
Premium export and cinematic story when entitlement allows.

## Settings
Every onboarding choice can be changed here.
Privacy and memory controls are first-class.
Animation and environment controls are real settings.

## Pricing
Free must be genuinely useful.
Premium adds depth, not basic emotional support.
Ads are non-intrusive, privacy-conscious and never based on conversations/moods/memories.
