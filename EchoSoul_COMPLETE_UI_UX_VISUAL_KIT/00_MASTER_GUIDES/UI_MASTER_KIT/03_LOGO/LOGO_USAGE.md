# Logo Usage

Primary mark: `echosoul-mark.svg`
Primary dark-surface wordmark: `echosoul-wordmark-dark.svg`
Light-surface wordmark: `echosoul-wordmark-light.svg`

Rules:
- Keep clear space at least the height of the inner mark.
- Never stretch or skew.
- Never add gradients to the logo itself beyond the supplied controlled mark.
- Do not use the logo as a generic decorative watermark.
- Use the mark alone for compact navigation/mobile.
