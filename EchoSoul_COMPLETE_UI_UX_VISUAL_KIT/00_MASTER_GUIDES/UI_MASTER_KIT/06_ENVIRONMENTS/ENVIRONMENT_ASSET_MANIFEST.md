# Environment Asset Manifest

For each environment create separate files where practical:

sky.webp
sun.webp / moon.webp
clouds_far.webp
clouds_near.webp
mountains.webp
trees_mid.webp
foliage_front.webp
room_base.webp
window.webp
lamp_body.webp
lamp_glow.webp
candle_flame.webp
mist.webp
rain.webp / snow.webp
particles.webp
ambient-loop.ogg
environment-motion.md

Naming convention:
<environment>-<layer>-<variant>.<ext>

Examples:
rainy-night-clouds-far.webp
rainy-night-lamp-glow.webp
mountain-dawn-mist.webp
cozy-room-candle-flame.webp
