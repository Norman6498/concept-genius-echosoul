# Tabs & Component States

## Primary tabs
Use a restrained capsule only for navigation categories:
For You / Poetry / Shayari / Authors / Books / Life Lessons / Short Reads
Calm / Sleep / Motivation / Focus / Overthinking / Anger / Healing / Energize
Overview / Timeline / Mood Patterns / Growth Insights / Milestones / Life Lessons / Your Story

## States
Default: dark translucent surface.
Hover: slight lift + border increase.
Active: warm ivory/gold fill with dark text OR a clear gold underline depending on context.
Focus: 2px accessible focus ring.
Disabled: 45% opacity, no glow.

## Interaction
Tabs must be keyboard navigable.
On mobile, horizontally scroll rather than wrapping into a giant multi-row block.
Do not use tabs as decorative labels.
