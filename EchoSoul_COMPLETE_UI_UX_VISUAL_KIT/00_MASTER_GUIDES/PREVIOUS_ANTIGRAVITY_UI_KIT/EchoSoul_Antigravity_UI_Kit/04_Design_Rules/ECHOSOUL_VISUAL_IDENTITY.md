# EchoSoul Visual Identity — Locked Direction

## Core feeling
The product should feel like entering a real realm of life, comfort, reflection, literature, and personal story.

## Product identity
EchoSoul can act as:
- Friend
- Teacher
- Guru-like guide / source of perspective
- Literary companion
- Memory keeper
- Storyteller
- Creative experience guide

## Core visual universe
Combine these as one identity, changing emphasis by product context:
1. Midnight Soul — conversation, deep reflection, home
2. Ink & Soul — literature, poetry, novel, words
3. Dream Realm — scenes, animation, cinematic experiences
4. Warm Memory — moments and personal history
5. Literary Cinema — major transitions, premium storytelling
6. Quiet Sanctuary — calm reflection and journey

## Signature visual language
Light -> ripple -> soul -> ink -> words -> memory -> story -> experience

## Typography
Elegant serif for display/editorial moments; clean modern sans-serif for interface text.

## Color family
Deep midnight/charcoal, warm ivory, muted gold/amber, with restrained secondary notes such as lavender, forest, burgundy, and silver where contextually useful.

## Motion
Subtle, smooth, meaningful, never distracting. Respect reduced-motion preferences.

## Photography / imagery
Human moments can be obscured or non-identifying; rooms, windows, rain, night, landscapes, books, ink, dreamlike/surreal scenes, and tasteful illustration are preferred.

## Prohibitions
- No generic AI SaaS dashboard look.
- No random stock imagery that breaks the world.
- No fake quotes presented as authentic literature.
- No human-like AI avatar as the default identity.
- No visual style change that makes each feature feel like a different brand.
