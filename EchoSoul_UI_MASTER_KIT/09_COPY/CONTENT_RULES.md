# EchoSoul Content Rules

## Never fabricate
Do not invent:
- author names
- poetry
- shayari
- book passages
- user memories
- testimonials
- statistics
- pricing claims
- rights/licensing status

## Literary text
Authentic source text must carry provenance: author, work, language, source, rights status/evidence, version/checksum where applicable.

Language and script are separate:
- Urdu language can be displayed in Devanagari when the user chooses that script.
- Do not assume Urdu language means Urdu/Perso-Arabic script.
- Preserve source script when authenticity requires it; provide user-selected rendering only where the transformation is legitimate.

## AI response style
Listen first.
Reflect briefly.
Use relevant history only when useful and safe.
Give one practical next step by default.
Surface Words/Music/Scene only when they are actually relevant.
Do not force every modality into every response.
