# Time-of-Day System

Auto mode follows local user time. Transitions are gradual, not hard swaps.

05:00–07:00 Early Morning — quiet, calm, fresh, hopeful
07:00–10:00 Morning — bright, energetic, focused
10:00–12:00 Late Morning — clear, productive, balanced
12:00–16:00 Afternoon — warm, lively, active
16:00–19:00 Evening — golden, reflective, peaceful
19:00–23:00 Night — cozy, safe, intimate
23:00–02:00 Late Night — deep, still, dreamy

Transition rules:
- sky color/lighting crossfade
- shadows shift gradually
- lamp intensity increases toward evening/night
- stars appear progressively
- ambient audio crossfades
- weather can vary independently
- scene objects retain continuity

Settings:
Auto / Day / Night / Custom.
Custom must allow user control without breaking the core EchoSoul identity.
