# Accessibility & Responsive Rules

- WCAG-conscious contrast.
- Keyboard navigation for every interactive control.
- Visible focus state.
- Semantic headings and landmarks.
- Labels for icon-only controls.
- Voice controls must have text alternatives.
- Do not encode meaning by color alone.
- Respect `prefers-reduced-motion`.
- Captions/transcripts for audio/video where applicable.
- Mobile controls must remain reachable and thumb-friendly.
- Never trap keyboard focus except in deliberate modal/dialog states.
