# EchoSoul — UX and Flow Specification

## Navigation
1. Home
2. Moments
3. Words
4. Scenes
5. Journey
6. Memory

## Home
Hero: “Talk to me.”
Modes: Voice, Type, Just Listen.
Below: recent moment, Today's Plan, quick action entry.

## Conversation
Top: session mode + privacy/memory indicator.
Middle: messages.
Bottom: mic/type controls.
After listening: feature drawer with Words, Book/Page, Animation, Scene, Video, Perspective, Plan, Just Stay Here.

## Moment Summary
Sections: What I heard, emotional theme, what mattered, optional memory candidate, next actions.

## Words
Search and browse real works. Filters: language, author, genre, theme, intensity. Every result has provenance.

## Animated Literature
Full-screen paper-like experience. Text appears to be written by a pen/brush. User can control speed, replay, pause, voice reading, and save.

## Scenes
Preview the proposed creative interpretation. Then Generate. Show job progress and allow cancellation where provider supports it.

## Moments
Chronological and thematic timeline. Each moment can hold summary, selected literary work, animation, scene/video, and linked memory IDs.

## Journey
Novel view. Chapters are built from approved moments. Growth and reflection cards are clearly labeled as reflections.

## Memory
Search, filter, edit, delete. Categories: About Me, People, Patterns, Preferences, Goals, Moments.

## Settings
Language, support style, voice, memory controls, private-session defaults, notifications, export/delete, subscription.

## Main flow
Home -> Conversation -> Safety Gate -> Context -> Relevant Memory -> Response -> User chooses next feature -> Result -> Save/Forget -> Moment/Novel update.

## Creative flow
Conversation -> Make Scene/Animation/Video -> Concept preview -> User accepts/edits -> Async generation -> Preview -> Save/Discard.

## Literature flow
Conversation -> Find My Words -> Retrieval -> Rights/provenance gate -> Ranked result -> Animated presentation -> Save/Another result.

## Critical interaction rule
The post-listening screen is a **choice point**, not a forced funnel. The user can end the session without generating anything.
