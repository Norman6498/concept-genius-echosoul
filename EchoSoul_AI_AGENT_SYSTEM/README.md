# EchoSoul AI Agent System — Complete Package

This package defines the specialized-agent architecture for EchoSoul.

## Core idea

EchoSoul is not one generic LLM prompt.

It is:
Supervisor
+ Safety
+ Context
+ Memory
+ Response
+ Literature
+ Music
+ Scenes
+ Moments
+ Journey
+ Life Novel
+ Quality control
+ deterministic services.

## 27 specialized agents are defined.

Each has a dedicated prompt and clear responsibility.

## Important

“Training” at MVP means:
prompt engineering + examples + retrieval + tools + schemas + evaluators + regression testing.

Do not fine-tune prematurely.

## Free AI

The free model catalog is volatile. Model assignments are therefore capability-based and configurable.

Use synthetic/anonymized data for benchmarking free providers until their data policies are verified as compatible with EchoSoul's privacy promises.

## Build order

P0 orchestration and safety first.
Then memory/response.
Then literature.
Then music/scenes/moments.
Then Journey.
Then Life Novel.
Then premium/creative optimization.
