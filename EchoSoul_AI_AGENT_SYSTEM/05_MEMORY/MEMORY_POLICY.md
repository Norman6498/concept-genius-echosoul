# EchoSoul Memory Policy

## Store
- explicit stable preferences
- explicit goals
- repeated themes
- meaningful milestones
- user-approved moments
- useful relationship context when appropriate

## Do not store by default
- transient mood
- unnecessary sensitive details
- passwords/credentials
- unsupported inference
- every conversation line
- private-session content

## Retrieval
A memory is eligible only when:
relevance × usefulness × confidence × safety is high enough.

## User control
Users can:
view
edit
delete
export
disable memory
mark a conversation private

## Private mode
Private sessions do not create persistent memory.
