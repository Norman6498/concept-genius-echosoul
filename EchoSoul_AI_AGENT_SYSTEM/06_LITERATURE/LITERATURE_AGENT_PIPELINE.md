# Literature Agent Pipeline

User moment
→ A10 query specification
→ metadata/keyword/embedding retrieval
→ provenance filter
→ A11 rerank
→ A12 explanation
→ exact source text renderer

Required metadata:
author
title
language
script
publication information
source
rights status/evidence
ingestion version
checksum where practical

No source text mutation.

Do not use AI-generated poetry as an authentic literature result.
